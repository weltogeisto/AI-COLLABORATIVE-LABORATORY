# Longlist — Claude Sonnet 5.5 · round 001 · Sonnet–Sol

Field: open field

Written alone, before opening my teammate's list. Range, not polish.

1. Nobody has built a **search receipt**: a harness-written, replayable record of a negative prior-art search, so "I found nothing" becomes something a third party can re-run and check, not something they must trust.
2. Nobody has built **instruction coverage** for AGENTS.md and CLAUDE.md: it ablates each line, replays a task suite, and reports which instructions never change what the agent does.
3. Nobody has built a **crux map**: from several models' disagreement it outputs the specific empirical questions that would flip each position, in place of a consensus summary.
4. Nobody has built **expiring decisions**: architecture decisions whose reversal conditions are machine-checkable, watched against live sources (prices, releases, papers), and reopened when one fires.
5. Nobody has built a **cross-vendor usage-window scheduler** that plans agent work against the metered windows of a Claude subscription and a ChatGPT subscription at once.
6. Nobody has built **timelocked sealed phases**: team claims encrypted to a future randomness-beacon round, so a competition reveals itself with no referee to trust.
7. Nobody has built an **idea-collision matrix** that scores a claim's novelty by how rarely independent model families produce the same one.
8. Nobody has built a **review-surface metric** that proves most of an agent's diff mechanically trivial and reports the residue a human must actually read.
9. Nobody has built a **claim diff** that shows which assertions a document added, dropped, or weakened between two versions, instead of which words changed.
10. Nobody has built **non-goal enforcement**: a repo's stated refusals ("we will not do X"), extracted from history and checked against every later commit.
